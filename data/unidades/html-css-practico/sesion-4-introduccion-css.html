¿Qué es CSS?

Hasta ahora tu página tiene contenido y estructura (HTML), pero no aspecto propio: el navegador la pinta con sus valores por defecto. CSS (Cascading Style Sheets) es el lenguaje que decide cómo se ve cada cosa: colores, tipografía, tamaños, espaciados...

Una regla CSS siempre tiene la misma forma: un selector (a qué le aplicas el estilo) y, entre llaves, una o varias parejas de propiedad y valor:

selector {
    propiedad: valor;
}
🤔 Antes de seguir: fíjate en la sintaxis, ¿qué símbolo termina cada propiedad, y qué símbolos envuelven el bloque entero?
Ver la respuesta

Cada propiedad termina en punto y coma ;, y el bloque entero de declaraciones va entre llaves { }. Olvidar el ; es el error más común al empezar con CSS — en algunos casos puede hacer que el navegador ignore también la propiedad siguiente, así que si una regla "no hace nada", repasa primero los puntos y coma.

Tu primera regla: el estilo interno

Para probar CSS rápido, se puede escribir dentro de una etiqueta <style>, colocada en el <head> del documento:

<head>
    <title>Mi página</title>
    <style>
        h1 {
            color: darkblue;
        }
    </style>
</head>

Ese h1 es el selector: significa "aplica esto a todas las etiquetas <h1> de la página".

Ejercicio guiado 1 — Tu primer <style>

  1. Crea un archivo nuevo prueba-css.html con la estructura básica de siempre (<!DOCTYPE html>, <html>, <head>, <body>).
  2. Dentro del <body>, escribe un <h1> con tu nombre y dos <p> con lo que quieras.
  3. En el <head>, añade una etiqueta <style> con una regla que ponga el <h1> de color darkblue.

Si lo has hecho bien: al abrir Live Server, solo tu <h1> cambiará de color — los dos párrafos seguirán en negro, porque la regla usa el selector h1, que no afecta a <p>.

Selectores: etiqueta, clase e id

El selector h1 afecta a todos los <h1> de la página. Para ser más concreto hay dos herramientas más:

SelectorSe escribeAfecta a
Etiquetap { }Todos los <p> de la página
Clase.destacado { }Todo elemento con class="destacado", sean el que sean y estén donde estén
Id#cabecera { }El único elemento con id="cabecera" (un id no se repite en la página)
<p class="destacado">Este párrafo es especial</p>

.destacado {
    color: darkred;
}
Regla práctica: usa etiqueta cuando quieras afectar a todos por igual, clase cuando quieras reutilizar el mismo estilo en varios sitios sueltos, e id solo para ese elemento único (por ejemplo, tu cabecera principal).

Compáralos: el mismo HTML, tres CSS distintos

La tabla dice a quién afecta cada uno, pero para verlo de verdad hace falta compararlos sobre el mismo HTML. Parte siempre de esto:

<p>Uno</p>
<p class="destacado">Dos</p>
<p id="especial">Tres</p>

Y aplícale, una a una, estas tres reglas (fíjate en que la única propiedad que cambia entre las tres es el selector):

🤔 Antes de seguir: si al párrafo "Dos" le añades también id="especial" (además de su class="destacado" de antes), ¿podrían aplicarse las reglas .destacado y #especial a la vez sobre ese mismo párrafo?
Ver la respuesta

Sí. Clase e id son atributos distintos, así que un mismo elemento puede tener los dos a la vez, y las dos reglas (.destacado y #especial) se aplicarían juntas sobre él, junto con cualquier regla de etiqueta (p { }) que también exista. CSS no obliga a elegir un único selector por elemento: es normal que varias reglas distintas aporten cada una una parte del estilo final.

Ejercicio guiado 2 — Distingue clase e id

  1. En tu prueba-css.html, añade class="destacado" a uno de los dos párrafos.
  2. En el <style>, crea la regla .destacado con color: darkred;.
  3. Ahora añade id="titulo-principal" a tu <h1> y crea una regla #titulo-principal que le cambie el tamaño con font-size: 2.5em;.

Si lo has hecho bien: solo el párrafo con class="destacado" se verá en rojo oscuro (el otro párrafo sigue en negro), y solo tu <h1> crecerá de tamaño.

Colores

Un color en CSS se puede escribir de varias formas — de momento con dos te sobra:

FormaEjemplo
Nombre en ingléscolor: tomato;
Código hexadecimalcolor: #ff6347;

Las dos propiedades de color más usadas:

.caja {
    color: white;
    background-color: #2d2d30;
}
color + background-color
background-color: tomato
sin background-color (blanco por defecto)
⚠️ Cuidado con el contraste: si pones un background-color oscuro y no cambias también el color del texto, este puede quedar casi ilegible (por defecto el texto es negro).

Ejercicio guiado 3 — Colorea tu página de prueba

  1. Añade una tercera etiqueta a tu prueba-css.html: un <div> con class="caja" y algo de texto dentro.
  2. Crea la regla .caja con un background-color oscuro (a tu elección) y un color claro para el texto.
  3. Prueba a cambiar el background-color por un color con nombre (tomato, teal...) y luego por un código hexadecimal.

Si lo has hecho bien: tu <div> se verá como una caja de color con el texto claramente legible, y podrás cambiar su color cuantas veces quieras solo tocando el valor de background-color.

Tipografía

Cuatro propiedades para controlar cómo se ve el texto:

PropiedadPara qué sirve
font-familyLa tipografía (letra) a usar
font-sizeEl tamaño del texto
font-weightEl grosor: normal o bold
text-alignLa alineación: left, center, right

Para no confundir qué hace cada una, míralas por separado. Primero el grosor:

font-weight: normal;

font-weight: bold;

Ahora la alineación (fíjate en que solo cambia la posición del texto, nunca su grosor ni su tamaño):

text-align: left;

text-align: center;

text-align: right;

Las cuatro propiedades son independientes entre sí y se pueden combinar todas a la vez, por ejemplo en un <h1>:

h1 {
    font-family: Georgia, serif;
    font-size: 2em;
    font-weight: bold;
    text-align: center;
}

Así se ve

🤔 Antes de seguir: font-family acepta varios nombres separados por comas. ¿Para qué crees que sirve poner más de uno, si el navegador solo puede usar una tipografía a la vez?
Ver la respuesta

Es una lista de preferencia: el navegador prueba el primer nombre, y si no tiene esa tipografía instalada, pasa al siguiente de la lista. Por eso casi siempre se termina con una familia genérica (serif, sans-serif) como último recurso, para asegurarse de que, pase lo que pase, el texto se vea con algo razonable en vez de con la tipografía por defecto del navegador sin control ninguno.

Ejercicio guiado 4 — Tipografía en tu página de prueba

  1. A tu #titulo-principal, añade font-family, text-align: center; y font-weight: bold;.
  2. A la etiqueta p (todos los párrafos), añade font-size: 1.1em;.
  3. Prueba dos o tres tipografías distintas en font-family (por ejemplo Georgia, serif, luego "Courier New", monospace) y quédate con la que más te guste.

Si lo has hecho bien: tu título quedará centrado y en negrita con la tipografía elegida, y todos tus párrafos (no solo uno) habrán crecido ligeramente de tamaño a la vez, porque p es un selector de etiqueta.

Estilo externo: tu propia hoja de estilos

Escribir el CSS dentro de <style> está bien para probar rápido, pero tu web personal (la que llevas construyendo desde la sesión 1) va a tener varias páginas y muchas reglas — repetirlas en cada archivo sería un desastre de mantener. La solución: un archivo .css aparte, enlazado desde el HTML:

<head>
    <title>Mi página</title>
    <link rel="stylesheet" href="estilos.css">
</head>

El archivo estilos.css lleva solo las reglas, sin <style> ni ninguna otra etiqueta HTML alrededor:

h1 {
    color: darkblue;
}
Ventaja de separarlo: si mañana cambias un color, lo cambias una vez en estilos.css y se actualiza en todas las páginas que lo enlacen — no tienes que tocar cada .html uno a uno.
⚠️ El href="estilos.css" del <link> es una ruta, exactamente igual que el src de una imagen (sesión 3): si el nombre no coincide con el archivo real, o el archivo no está en la misma carpeta que el HTML, ninguna de tus reglas se aplicará — y como a partir de ahora todo tu CSS vive ahí, te quedarías sin estilos el resto de la sesión sin ningún aviso de error. Si al guardar no ves ningún cambio, esto es lo primero que hay que revisar.

Ejercicio guiado 5 — Pasa tu web a un archivo externo

  1. En tu carpeta mi-web, crea un archivo nuevo llamado estilos.css.
  2. En tu index.html, añade dentro del <head> la línea <link rel="stylesheet" href="estilos.css">.
  3. Copia dentro de estilos.css las reglas que has ido probando en prueba-css.html (adapta los selectores a las clases e ids que ya tengas en tu index.html: tu <header>, tus <section>...).
  4. Aplica al menos: un color de fondo para el <body> o el <header>, una tipografía para los títulos, y una clase reutilizada en dos sitios distintos de tu página.

Si lo has hecho bien: al recargar con Live Server, tu web ya no se verá "a pelo" — tendrá tus colores y tu tipografía. Si no cambia nada, comprueba primero el nombre del archivo en href (mayúsculas, extensión...), tal y como avisa la nota de arriba.

Retos

Los tres retos son obligatorios, en orden: cada uno se apoya en el anterior. Si te atascas en alguno, dilo — es normal no encontrar la solución a la primera y para eso estoy yo.

Reto 1 — Una paleta de dos colores

Elige dos colores que combinen bien entre sí (uno de fondo, otro de texto o acento) y aplícalos de forma consistente en toda tu web: mismo color de fondo para el <header> y el <footer>, mismo color de acento para los títulos. Nada de colores distintos en cada sección "porque sí".

Reto 2 — Investiga: :hover

Este selector no lo hemos explicado en clase. Entra en la referencia de MDN sobre :hover y busca, en los ejemplos, cómo se escribe combinado con otro selector (fíjate en el ejemplo que usa la etiqueta <a>). Úsalo para que tus enlaces cambien de color cuando pases el ratón por encima.

Pista si te atascas

En la página de MDN, busca el apartado de ejemplos y localiza el bloque de CSS que combina un selector de etiqueta con :hover pegado justo detrás, sin espacio. El selector que necesitas combinar con :hover es el de la etiqueta que envuelve un enlace.

Reto 3 — Todo junto

Revisa tu web completa y comprueba que cumple todo esto a la vez:

  • Todo el CSS está en tu archivo estilos.css externo — nada de <style> ni style="..." sueltos en el HTML.
  • Usas al menos una clase reutilizada en dos o más elementos distintos.
  • Tu paleta de colores es consistente (Reto 1).
  • Tus títulos tienen una tipografía y una alineación decididas por ti, no las que trae el navegador por defecto.
  • El enlace con :hover del Reto 2 funciona.
Guarda esta versión — ya tienes una web con estructura semántica (sesión 3) y estilo propio (hoy). En la próxima sesión llega el modelo de caja: margin, padding y border, para controlar el espacio alrededor de cada elemento.
